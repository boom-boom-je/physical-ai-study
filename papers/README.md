## 읽는 방법
1회차: 초록·그림·결론만 (30분) → 2회차: 방법 (수식은 표기만 확인) → 3회차: 내 프로젝트 관점에서 정리. 번역 도구를 써도 된다.

## 목표
논문 한 편의 문제, 핵심 아이디어, 실험, 한계를 5분 안에 말로 설명할 수 있다.
