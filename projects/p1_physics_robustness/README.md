# Project 1 · 물리 값이 바뀌면 로봇의 정책은 얼마나 무너지는가

**기간** 11/16 ~ 12/31 (약 33시간)

## 연구 질문
고정된 물리 값으로 학습한 정책은 마찰·질량 변화에 얼마나 취약한가? 도메인 랜덤화는 이를 얼마나 개선하고, 그 대가는 무엇인가?

## 환경
- Gymnasium MuJoCo `HalfCheetah-v5` + Stable-Baselines3 PPO. HalfCheetah는 넘어져도 에피소드가 끝나지 않아 입문용으로 다루기 쉽다.
- 물리 값: `env.unwrapped.model.geom_friction`(마찰), `env.unwrapped.model.body_mass`(질량)을 바꿔 조절한다. 원래 값을 저장해 두고 배율로 바꾼다.
- 학습이 잘 안 되면 RL Baselines3 Zoo의 검증된 하이퍼파라미터로 먼저 돌려 본다: https://github.com/DLR-RM/rl-baselines3-zoo

## 학습 목표
- [ ] 강화학습 실험을 재현 가능하게 설계할 수 있다 (설정 파일, 시드 3개, 평균±표준편차)
- [ ] Domain Randomization의 원리와 장단점을 실험 결과로 설명할 수 있다
- [ ] 연구 질문 → 실험 → 결과 → 한계로 이어지는 연구 정리 방식을 익힌다
