# Project 2 · 간단한 적응 모듈 만들기 (RMA 단순화 버전)

**기간** 1월 ~ 2월 (약 50시간) · 프리랩이 시작되면 연구실 주제·장비에 맞춰 조정한다.

## 연구 질문
최근 움직임 기록만으로 물리 값을 추정하고, 그 추정값으로 정책이 변화에 적응할 수 있는가?

## 환경
Project 1과 같은 환경과 물리 값 범위를 그대로 써서 결과를 직접 비교한다.

## 학습 목표
- [ ] System Identification과 Online Adaptation을 직접 구현해 보고 차이를 설명할 수 있다
- [ ] 지도학습(회귀)을 강화학습 정책과 결합할 수 있다
- [ ] RMA 논문의 구조와, 이 프로젝트의 단순화가 원래 방법과 어떻게 다른지 설명할 수 있다

## 마일스톤
| 마일스톤 | 기간 | 할 일 | 산출물 | 완료 기준 |
|---|---|---|---|---|
| M1 특권 정책 | 1월 1~2주 | 실제 마찰·질량 값을 관측에 추가해 학습 (정답을 아는 정책 = 성능 상한) | 특권 정책과 DR 정책 비교 | 상한과 DR 사이 격차를 수치로 제시할 수 있다 |
| M2 물리 값 추정기 | 1월 3~4주 | 여러 물리 값에서 (최근 N스텝 상태·행동, 실제 물리 값) 쌍을 모아 MLP로 회귀 | 기록 길이 N별 추정 오차 그래프 | N에 따라 오차가 어떻게 변하는지 설명할 수 있다 |
| M3 적응 정책 | 2월 1~2주 | 특권 정책에 실제 값 대신 추정값을 넣어 평가. 기준·DR·적응·특권 네 정책 비교 | 비교 표·그래프 (학습 범위 밖 포함) | 적응 정책이 DR보다 나은 조건과 이유를 설명할 수 있다 |
| M4 보고서 | 2월 3~4주 | README와 4쪽 안팎의 기술 보고서 (워크숍 논문 형식) | 보고서 PDF, 공개 저장소 | 연구실 면담에서 10분 발표를 할 수 있다 |

## 원래 RMA와의 차이
RMA는 물리 값을 직접 맞히지 않고, 환경 정보를 압축한 잠재 벡터를 추정한다. 이 프로젝트는 이해하기 쉽도록 물리 값을 직접 추정하는 단순화 버전이다. 면담에서 이 차이와, 원래 방식이 잠재 벡터를 쓰는 이유를 설명할 수 있어야 한다.
